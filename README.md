# Fishing Helper

**Forever Fishing** is a Windows desktop fishing helper developed for WoW Forever. It casts, locates the bobber, confirms it with the interaction cursor, watches for a bite, and right-clicks to retrieve the catch.

## Download

Get the Windows x64 ZIP from [Releases](https://github.com/Kaurus2/Fishing-Helper/releases/latest). Extract it into a writable folder and open **ForeverFishing.exe** directly.

The helper starts **OFF**. Its current fishing detection remains under evaluation; catches can be missed, particularly in difficult scenes. The October 18 release adds the updater and retains the existing fishing detection behavior.

## Getting started

1. Open WoW in windowed or borderless mode and enable Auto Loot.
2. In the helper's Settings, select the WoW window and set **Cast** to your Fishing key. The default is **E**.
3. Adjust the camera so casts land inside the red **Bobber Cast Area**.
4. With WoW focused, press **F8** to start or stop. **F9** exits. Shortcuts can be changed in Settings.

Settings also include optional auto bait, a copyable bait macro, sound assist and advanced timing controls. The helper remembers its position, pin state and saved shortcuts. It pauses game input when the selected game window is unfocused.

## Updates

The helper checks for public stable releases on startup and every six hours. Click the version in the footer to check manually. When a newer release is available, a gold **Update…** button opens its notes. Choose **Update & restart** to install it.

The downloaded executable is checked against GitHub's SHA-256 digest and its embedded app/version metadata. Saved settings remain in place, and the previous executable is backed up beside the app. Fishing stays **OFF** after restart.

Builds from before **v2026.10.18.1** need this first updater-enabled build installed manually. Later updates can be installed from within the app.
